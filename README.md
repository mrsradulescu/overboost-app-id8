# OVERBOOST for iDrive 8 (MGU21)

One app with a main menu: **M Vitals**, **Drag Timer**, **Fault Scanner**, **Engine Config**.
The logic comes from the open-source idrive7-apps project; the screens are plain HMI rows (proven on iDrive 8).

This repository is a **Store source** (mgu-store, "Repo tree" layout, see `docs/PUBLISHING.md` there): the car's Store installs
OVERBOOST from it and updates it when a new version is pushed here. Nothing else has to be done on the laptop.

## Install on the car (once)
1. The head unit needs the Store (mgu-store's installer: `mgu-install.js first-install`, or the toolkit) and an internet connection.
2. Store -> **Sources** -> **Add source** -> GitHub -> `mrsradulescu/overboost-app-id8` -> channel **Branch: main**.
3. Open the new source, pick **OVERBOOST**, **Install**. The Store installs `app-privacy`, `mgu-render` and `mgu-deploy` first when
   they are missing, then builds the app on the unit against the oap-sdk of a stock BMW app (no BMW file is in this repository).
4. On iDrive 8 the install is live when the unit's app manager takes it; otherwise it is queued and applied at the next start.
   Restart the head unit if the tile does not show after a few minutes.

An OVERBOOST put on the car by the toolkit is the same app (same id `overboost`). It has no recorded origin, so the Store updates it
from the source whose listing has the same title (the app's en_GB text, `OVERBOOST`): this one.

## Update
Push a new version here, the car's Store shows it under **Updates** (Store -> Check). To publish one:
1. Change the code in `src/` / `app/`, raise `version` in `app/version.json` (keep `base`).
2. `python3 tools/store_tree.py` rewrites `apps/overboost/` (the source package the Store builds); `python3 tools/store_tree.py --check`
   says whether it is up to date. Needs Python 3 and Node.js.
3. Commit everything, including `apps/overboost/`, and push to `main`.

The Store compares **versions** on a branch (a push with the same version only counts as an update if it changes the app's files).
Always raise the version.

## Layout
| Path | |
|---|---|
| `mgu-repo.json` | what the Store reads: one component, `overboost`, an app for iDrive 8 built on the unit |
| `apps/overboost/` | generated by `tools/store_tree.py`: `mgu-app.json`, the flattened modules, the staged package tree |
| `src/`, `app/` | the sources the package is made from |
| `tools/store_tree.py` | the generator and its checks |

## Fault Scanner texts
`src/dtc_db.pack` (~3.5 MB) is the fault-text database the Fault Scanner reads; `tools/store_tree.py` puts it into the package
(`apps/overboost/package/javascript/`). Without it the Fault Scanner still lists faults with their codes, but shows texts only for the
codes in `src/known_texts.js`. It is built from the units' SGBD texts with idrive7-apps' `kit/tools/dtc_texts.py` / `dtc_tables.py`.
IterioDev's Fault Codes app publishes its texts in its package too.

## Uninstall
Store -> OVERBOOST -> **Remove**. The Store removes it the way the deploy tool does (`mgu-deploy uninstall overboost`).

For iDrive 7 there is a separate source: `mrsradulescu/overboost-app-id7`.
